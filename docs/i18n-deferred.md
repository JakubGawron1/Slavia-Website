# i18n — odłożone (Fala 4)

Aplikacja pozostaje **PL-only**. Przy wdrożeniu `@nuxtjs/i18n`:

1. `config/i18n.ts` — `defaultLocale`, `availableLocales`
2. `nuxt.config.ts` — moduł `@nuxtjs/i18n`, lazy `locales/pl.json`
3. Start od tras publicznych (`/`, `/zawodnicy`, kalkulatory), panele kadry później
4. Mobile: `flutter_localizations` + ARB po stabilizacji WWW
